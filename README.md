# Castle Yokai
A 2D pixel art platformer with inspiration from Japanese Folklore

https://parabolink.itch.io/castle-yokai

## Requirements
- Godot 3.6.1

## Music
Music is written in FL Studio using the following 3rd party plugins
- [NES VST 1.2](https://www.mattmontag.com/projects-page/nintendo-vst)
- [Famisynth II](https://mu-station.chillout.jp/plugins/FAMISYNTH-II/index.html)
- [Magical 8 bit Plugin 2](https://ymck.net/app/magical-8bit-plug-en)

#### Note to self
When transferring computers check the following directories:
- G:\My Drive\MY MUSIC\VST Plugins
- C:\Program Files\Steinberg\VstPlugins
